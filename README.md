# BILYARD CLUB

BILYARD CLUB — Windows kompyuterlar uchun Tkinter va SQLite asosida ishlaydigan billiard/tennis klub boshqaruv dasturi.

## Imkoniyatlar

- 5 ta billiard stoli va 3 ta tennis stoli
- Stolni band qilish, vaqt hisoblagichi, pauza va tugatish
- Stolga ichimlik va gazak mahsulotlarini qo‘shish
- Kunlik, haftalik va oylik hisobotlar
- Mahsulot narxi va tannarxini boshqarish
- Kirish va admin paroli
- Ma’lumotlarni SQLite bazasida saqlash

## Talablar

- Windows 10/11
- Python 3.10 yoki yangiroq
- Tkinter (Python o‘rnatishda Tcl/Tk komponenti)

## Ishga tushirish

1. Python'ni o‘rnating: https://www.python.org/downloads/
2. Ushbu repository papkasini kompyuteringizga yuklab oling.
3. Terminal/CMD oynasida shu papkaga kiring.
4. Dasturni ishga tushiring:

```bash
python main.py
```

`requirements.txt` faylida tashqi kutubxonalar yo‘q, chunki dastur Python standart kutubxonalaridan foydalanadi.

## Ma’lumotlar

Dastur birinchi marta ishga tushganda `club_data.db` ma’lumotlar bazasini va `club_images` papkasini yaratadi. Ularni o‘chirib yubormang — klub ma’lumotlari shu bazada saqlanadi.

## Eslatma

Bu GitHub'ga yuklash uchun tayyorlangan loyiha to‘plami. GitHub repository'ga joylash dasturni avtomatik ravishda internetda ishlaydigan saytga aylantirmaydi. Dastur hozircha Windows desktop ilovasi.
